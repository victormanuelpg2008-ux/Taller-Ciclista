# Taller Ciclista
Este taller fue desarrollado en **Java** alrededor de **Maven**, con un enfoque dirigido a la gestión orientada a objetos de una competencia de ciclismo y sus distintos tipos de corredores (como Velocistas, Contrarrelojistas, Escaladores,).

## Estructura del Taller
El código fuente se encuentra organizado dentro del paquete principal `com.`, implementando conceptos clave de la programación orientada a objetos como:
* **Polimorfismo**: Sobrescritura de métodos (`@Override`) para la impresión de tipos de ciclistas y sus estadísticas.
* **Encapsulamiento**: atributos privados con sus respectivos métodos de acceso (`getters` y `setters`).
* **Herencia**: clases derivadas a partir de una clase abstracta base (`Ciclista`).
